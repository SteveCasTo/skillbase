Investigación exclusivamente read-only: el fichero privado conservaba API histórica `55321`, pero el original activo y `.env` usan **54321 / DB 55322**. ### Limitación concreta de `action` en Sileo 0.1.5

El vendor renderiza el toast exterior como `<button>` (`dist/index.js`, render Sileo) y el CTA `button` como otro `<button>` dentro. El CTA está visible y su clic navega, pero `getByRole('button', {name:'Ver configuración'})` da **0**: no se expone como botón en el árbol accesible. Se observó, no se ocultó con roles artificiales ni se rebajó una expectativa. Los productores actuales no usan ese CTA; introducirlo en producto requiere corregir upstream/vendor o autorizar una actualización/vendorización fuera del ownership de este PR. **Esta es la decisión externa mínima pendiente; no se modificaron package/lock/node_modules.** No declarar WCAG completo ni action accesible PASS.
